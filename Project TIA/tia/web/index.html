    6. Configuration 
    
  
    Per-tenant limits, severity rules, criticality and path prefixes. Every save is a new immutable version.
    
  
    Skip files TIA should not analyse (vendored, generated, minified)
    
    Add path patterns under paths → exclude_patterns, for example
      "paths": {"strip_prefixes": [], "exclude_patterns": ["vendor/**", "**/generated/**", "*.min.js"]}.
      * stays within one folder, ** crosses folders, and a pattern without a folder also matches the file name anywhere.
      Up to 100 patterns. Anything defined in a skipped file is invisible to TIA, so a change to it reaches nothing. Every report records the patterns it ran with.
